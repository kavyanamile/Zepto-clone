## 📖 About the Project

This project is a **Zepto-inspired grocery delivery website clone** developed using **HTML5 and CSS3**.

The main goal of this project is to create a modern e-commerce user interface similar to quick-commerce platforms. It includes a responsive navigation bar, product sections, search interface, category display, and attractive product cards.

The website focuses on clean UI design, responsive layouts, and improving frontend development skills.

---

## ✨ Features

- 🏠 Modern Homepage Design
- 🔍 Search Bar Interface
- 📍 Location Selection UI
- 🛒 Product Categories
- 🥦 Grocery Product Cards
- 🎁 Offers Section
- 👤 Account Dropdown Menu
- 📱 Fully Responsive Design
- ✨ Smooth Hover Animations
