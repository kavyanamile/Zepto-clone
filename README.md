## 📖 About the Project

Zepto Clone is a frontend website inspired by the Zepto grocery delivery platform.

This project is created using **HTML5 and CSS3** to design a modern online grocery shopping interface with a clean layout, responsive design, and attractive user interface.

The project focuses on building a real-world e-commerce website structure using only frontend technologies.

---

## ✨ Features

- 🏠 Modern Homepage Layout
- 🔍 Search Bar Design
- 📍 Location 
- 👤 Account
- 🛒 Product Cards
- 🥦 Grocery Categories
- 📱 Mobile Responsive Design
- ✨ Hover Effects and Animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Responsive Web Design
